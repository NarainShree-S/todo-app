# ✅ Todo App

A full-stack Todo application with user login and registration.

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Java, Spring Boot
- **Database:** SQL

## ✨ Features
- User Registration and Login
- Add, view, update and delete todos
- Clean and responsive UI

## 🚀 How to Run
1. Clone the repository
2. Open backend in IntelliJ and run the main application
3. Open frontend/login.html in browser
4. App runs on http://localhost:8080
